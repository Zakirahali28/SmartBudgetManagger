# SmartBudgetManagger
A project for managing Budget.
SmartBudget Manager

1. Introduction

SmartBudget Manager is an Excel workbook designed to help users manage their monthly income and expenses.

2. Main Features

- Record monthly income and expenses.
- Categorize expenses.
- Calculate monthly balance automatically.
- Display charts of expenses by category.
- Receive warnings when the budget limit is exceeded.

3. Workbook Structure

The workbook contains three worksheets:

- Dashboard: Displays monthly balance, total income, total expenses, and charts.
- Transactions: Allows users to enter income and expenses.
- Categories: Contains predefined categories such as Food, Transport, Rent, Health, and Education.

4. Requirements

- Microsoft Excel 2016, 2019, 2021, or Microsoft 365.
- A compatible Excel application.

5. Getting Started

1. Open the SmartBudget_Manager.xlsx workbook.
2. Go to the Transactions worksheet.
3. Enter your income and expenses.
4. Select the appropriate expense category.
5. Open the Dashboard to view your financial summary.

6. Calculations

The workbook uses SUM(), SUMIF(), or SUMIFS() formulas to calculate totals and expenses by category.
